# pycea-paper

Code, figures and manuscript source for the Pycea / TreeData methods paper:

> **Pycea: a scverse toolkit for single-cell lineage tracing analysis**
> William N. Colgan, Eric Weine, Matthew G. Jones, Jonathan S. Weissman, Nir Yosef

- [Pycea](https://github.com/YosefLab/pycea): lineage tracing analysis and visualization (`pycea-lineage` on PyPI)
- [TreeData](https://github.com/YosefLab/treedata): AnnData extended with trees (`treedata` on PyPI)
- Documentation and tutorials: <https://pycea.readthedocs.io>

Every panel in the paper is produced by a script in this repository, and every figure is assembled by script.
Figures 3 and 4 follow the `mouse-embryo` and `growth-dynamics` tutorials in the Pycea documentation.

## Repository layout

```
config.py           color palette used for all plots
Makefile            make fig1 | fig2 | fig3 | fig4 | figs1  (assemble figures from panels)
scripts/            common.py (paths, style, SVG assembly helpers) and one folder per figure
  fig1/ fig2/       overview and TreeData figures (simulated data)
  fig3/             mouse embryo example (E9.5-R1)
  fig4/             4T1 tumor growth and fitness example
  figs1/            benchmarks (TreeData vs AnnData, plotting, run times)
data/               small result tables used by the plotting scripts (see "Data" below)
manuscript/         LaTeX source (main.tex, sections/, references.bib, figures/)
```

## Figures

| Figure | Content | Data | Scripts |
|---|---|---|---|
| 1 | Overview and example workflow | simulated (Cassiopeia 3.0) | `scripts/fig1/` |
| 2 | TreeData structure and tree plotting | simulated | `scripts/fig2/` |
| 3 | Ancestral linkage and gene heritability, mouse embryo | Colgan et al. 2026 | `scripts/fig3/` |
| 4 | Clades, fitness and gene expression, 4T1 tumors | Koblan et al. 2025 | `scripts/fig4/` |
| S1 | Benchmarks | simulated | `scripts/figs1/` |

Run order (from the repository root):

1. **Analysis** (heavy; submitted to Slurm, see the headers of the `.sbatch` files):
   - Fig. 3: `scripts/fig3/prepare_linkage.py`, `prepare_moran.py`, then `panels_data.py --cache` (see `scripts/fig3/prepare.sbatch`)
   - Fig. 4: `scripts/fig4/prepare.py`, then `panels.py`
   - Fig. S1: the three commands in `scripts/figs1/benchmark.sbatch`
   - Figs. 1 and 2: `scripts/fig1/simulate.py`, then the panel scripts (the Makefile runs these)
2. **Panels**: the panel scripts write SVGs to `plots/<fig>/`.
3. **Assembly**: `make fig1 fig2 fig3 fig4 figs1` composes the panels into `manuscript/figures/figureN.pdf`.

## Manuscript

```bash
cd manuscript
make            # builds main.pdf with tectonic
python3 make_docx.py   # optional: Word version for coauthors (needs pandoc and pdftoppm)
```

`manuscript/vancouver.bst` is the Vancouver bibliography style (CTAN `vancouver`, LPPL), edited locally to print DOIs.
`manuscript/springer-vancouver-brackets.csl` is the Springer Vancouver CSL style used for the Word version.

## Data

- **Mouse embryo (Fig. 3):** Colgan et al. 2026. Trees, annotations and UMAP are loaded with `pycea.datasets.colgan26`;
  gene expression is available on Zenodo (<https://doi.org/10.5281/zenodo.19892784>).
- **4T1 tumors (Fig. 4):** Koblan et al. 2025, loaded with `pycea.datasets.koblan25`
  (original data: <https://doi.org/10.6084/m9.figshare.28473866>).
- Processed versions of both datasets used by Pycea: <https://doi.org/10.5281/zenodo.23195576>.
- Figures 1, 2 and S1 use simulated data generated by the scripts here.

Large intermediate files (per-cell tables, `.h5td` objects) are not tracked; they are regenerated by the scripts.
Only the small result tables listed in `.gitignore` (`data/fig3_moran.csv`, `data/fig4_gene_corr.csv`,
`data/figs1_*.csv`, `data/fig3_palettes.json`) are included.

## Notes on reproducing

- **Not tracked:** image files (`*.png`, `*.svg`, `*.ai`) are excluded to keep the repository small. This includes the
  hand-made inputs to Figs. 1 and 2 (`plots/ecosystem.png`, `plots/treedata_schema.png`, `plots/fig1/datatypes.png`
  and the tool logos), which `make fig1` and `make fig2` need; panel SVGs are regenerated by the panel scripts.
- **Cluster-specific paths:** the `Makefile`, `.sbatch` files and `scripts/fig3/prepare_moran.py` call a conda
  environment and read the embryo expression data from absolute paths on the authors' Slurm cluster
  (`/lab/solexa_weissman/...`). Edit these (or set `PY=...` for `make`) to run elsewhere.
- **Environment:** Python 3.12, Scanpy 1.12, AnnData 0.13, Pycea 0.4.0, TreeData 0.3.1, and Cassiopeia 3.0.0
  (GitHub `3.0.0` branch). The Cassiopeia 2.1.0 plotting comparison (Fig. S1B) needs a separate environment.
- Several analyses (ancestral linkage and Moran's I on about 260,000 cells) take roughly 10 minutes and tens to hundreds of
  GB of memory; run them on a compute node.
